# 💃 MARIA

*MathML Automatisch Renderen In ASCII*

Pet project to convert [MathML](https://www.w3.org/TR/MathML3/) into the [Dedicon](https://www.dedicon.nl/) linear notation using [MathCAT](https://github.com/daisy/MathCAT).
